RMAN COMMANDS - YEU CAU 4
========================

Chay trong CMD/PowerShell, khong chay trong SQL Developer:

    rman target /

Backup toan database:

    BACKUP DATABASE;

Backup database kem archive log:

    BACKUP DATABASE PLUS ARCHIVELOG;

Restore/recover co ban:

    SHUTDOWN IMMEDIATE;
    STARTUP MOUNT;
    RESTORE DATABASE;
    RECOVER DATABASE;
    ALTER DATABASE OPEN;

Ghi chu:
- RMAN phu hop backup/restore toan database.
- De point-in-time recovery tot can cau hinh ARCHIVELOG va retention policy.
- Trong demo do an, Data Pump + Flashback de thao tac nhanh hon tren schema CQ09.
